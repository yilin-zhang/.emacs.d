#+TITLE: .emacs.d

A personal Emacs configuration for macOS: =use-package= + ELPA/MELPA for
packages, [[https://github.com/meow-edit/meow][Meow]] for modal editing, =eglot= for LSP.

This README doubles as a map of the configuration -- see [[*Structure][Structure]] for
where things live, [[*Key bindings][Key bindings]] and [[*Commands][Commands]] for what is actually bound.

* Structure
** Load order
=early-init.el= runs first (GC and UI tweaks before the frame appears).
=init.el= then bootstraps =use-package=, registers the package archives
(GNU, NonGNU, MELPA), and requires the modules in =lisp/= in this order:

#+begin_src
init-basic -> init-keys -> init-dired -> init-org -> init-git ->
init-markup -> init-prog -> init-search -> init-completion ->
init-edit -> init-utils -> init-commands -> custom/custom-post.el
#+end_src

=init-keys= is loaded early, right after =init-basic=, because many later
modules reference meow -- color-rg in =init-search=, vterm in =init-utils=,
=yilin/disable-meow= in =init-prog=. Loading it up front means everything
downstream can rely on meow being available.

=custom/custom-post.el= is loaded last and is deliberately not tracked by
git; see [[*Customization][Customization]].

* Installation
** Clone the repository
#+begin_src sh
git clone https://github.com/yilin-zhang/.emacs.d.git ~/.emacs.d
cd ~/.emacs.d
#+end_src
** Install dependencies (macOS)
*** Global
#+begin_src sh
brew install coreutils
brew install --cask font-sarasa-gothic font-open-dyslexic-nerd-font
#+end_src
*** Package
**** color-rg
#+begin_src sh
brew install ripgrep
#+end_src
**** jinx
1. Install =enchant= and =pkgconf=
   #+begin_src sh
   brew install enchant pkgconf
   #+end_src

2. Override the configuration to use =AppleSpell= by default.
   Create or modify =~/.config/enchant/enchant.ordering=:
   #+begin_src
   *:AppleSpell
   en_US:AppleSpell
   #+end_src
**** nerd-icons
Install nerd fonts in Emacs: =M-x nerd-icons-install-fonts=
**** eglot-booster
Follow the instruction in [[https://github.com/blahgeek/emacs-lsp-booster][emacs-lsp-booster]].

** Surround (SPC SPC)
=SPC SPC= followed by a character wraps the selected region's
non-whitespace content in that character, pairing brackets
automatically.

#+begin_example
  keys      region "text" becomes
  ----      ---------------------
  =         =text=
  +         +text+
  *         *text*
  -         -text-
  /         /text/
  _         _text_
  ~         ~text~
  '         'text'
  "         "text"
  ( or )    (text)
  [ or ]    [text]
  { or }    {text}
  < or >    <text>
#+end_example

For a character not listed, =M-x yilin/surround-region= prompts for one. To add a permanent entry, extend =surround-region--specs= in
=site-lisp/surround-region.el=; the wrapper command and its key are
generated from the table.

* Local plugins
Checked-in local plugins in =site-lisp/=:

Third-party:
- =kind-nerd-icons.el=: icon integration for completion candidates using nerd
  icons.

Self-made:
- =indent-shift.el=: vim-style =>>= / =<<= for a region or the current
  line, bound to => = / =<= in meow normal state.  The shift width
  tracks the major mode.
- =surround-region.el=: wrap the selected region in a character.
  Provides =yilin/surround-region= plus generated per-character
  wrappers, collected in the =surround-region-map= prefix keymap bound
  to =SPC SPC= (see [[*Surround (SPC SPC)][Surround]]).
- =lazy-revert.el=: lazy buffer revert.
- =macmount.el=: mount, unmount, and eject external storage devices on macOS.
- =sailor.el=: personal journaling minor mode with a dedicated hl-todo
  keyword set (activated via the =sailor-enable= file-local variable).
- =org-agenda-compose.el=: composes =org-agenda-files= from a static
  user list and a hook of dynamic source functions (used for the
  denote agenda integration).
- =warmup.el=: warms up heavy packages piece by piece on idle time
  after startup, so the first =C-c a= (or other slow command)
  doesn't pause. Consumers declare what to warm up via the custom
  use-package keyword =:warmup (foo bar baz)=, e.g. Org's 17
  sub-packages are registered from =init-org.el='s =(use-package
  org ...)= form. Loading the package self-installs on
  =emacs-startup-hook= -- no mode toggle needed.

* Customization
Create =~/.emacs.d/custom/custom-post.el=.  It is loaded last, after every
module in =lisp/=, and is excluded from git -- everything personal goes
there: machine-specific paths, private packages, extra leader keys, and
any override of a setting made in =lisp/=.

Because it loads last, a plain =setq= there wins over the modules.  For
settings inside a package's =:config=, wrap yours in
=with-eval-after-load=.

The sections below cover the hooks that =lisp/= deliberately leaves open.

** Org
The main repository intentionally ships no hardcoded agenda paths.
All personal file configuration belongs in =custom-post.el=.

Agenda files are managed by the =org-agenda-compose= package (see
[[*Local plugins][Local plugins]]), which exposes a small public API
described below.

*** Agenda files
Set =org-agenda-compose-extra-files= to the list of files that should
always appear in =org-agenda-files=:
#+begin_src elisp
(setq org-agenda-compose-extra-files
      '("~/agenda.org"
        "~/work.org"))
#+end_src

This list is merged with any dynamic sources (see [[*Dynamic sources][Dynamic sources]])
and deduplicated into =org-agenda-files= by
=org-agenda-compose-refresh=, which runs:

- once when =org= finishes loading, and
- as a =:before= advice on every =org-agenda= invocation.

The refresh is cheap (=directory-files= is millisecond-range), so new
agenda entries -- including freshly tagged denote notes -- show up on
the next =C-c a= without restarting Emacs. A manual refresh is
available as =M-x org-agenda-compose-refresh=.

*** Capture default
=org-default-notes-file= (the =org-capture= destination when no
template specifies one) is conceptually separate from agenda files
and is not wrapped. Set it directly:
#+begin_src elisp
(setq org-default-notes-file "~/inbox.org")
#+end_src

*** Dynamic sources
=org-agenda-compose-functions= is a hook of zero-argument functions,
each returning a list of absolute file paths. Every refresh appends
the union of their results to =org-agenda-compose-extra-files=. The
denote integration (see [[*Denote][Denote]]) registers itself on this hook;
you can add your own sources the same way:
#+begin_src elisp
(defun my/project-agenda-files ()
  "Return all .org files under ~/projects/inbox/."
  (directory-files "~/projects/inbox/" t "\\.org\\'"))

(add-hook 'org-agenda-compose-functions #'my/project-agenda-files)
#+end_src

Source functions must return freshly-built lists and should stay in
the millisecond range since they run on every =C-c a=.

*** Bibliography
Bibliography support is =citar= + =org-cite= (=org-ref= was dropped).
=citar= itself is configured in =custom-post.el=; point it at your
=.bib= files there:
#+begin_src elisp
(setq citar-bibliography '("~/references.bib"))
#+end_src

** Denote
Set the denote bucket by setting =denote-directory=:
#+begin_src elisp
(setq denote-directory "~/notes/denote")
#+end_src

Denote notes whose filename contains the =_agenda= keyword are
automatically included in =org-agenda-files= via a dynamic source
registered on =org-agenda-compose-functions= (see [[*Dynamic sources][Dynamic sources]]).
The keyword is configurable:
#+begin_src elisp
(setq yilin/denote-agenda-keyword "todo")  ; match _todo instead
#+end_src

To opt out of the agenda integration entirely:
#+begin_src elisp
(remove-hook 'org-agenda-compose-functions
             #'yilin/denote-agenda-files)
#+end_src

** Sailor (journaling)
=sailor-mode= is a buffer-local minor mode that swaps in a
journal-specific =hl-todo= keyword set (=DINNER=, =THOUGHT=,
=BACKLOG=, ...) without polluting the global keywords used in
programming buffers. Activate it on a per-file basis by adding a
file-local variable to the journal file's first line:
#+begin_src org
# -*- sailor-enable: t; -*-
#+TITLE: My Journal
#+end_src
The flag is registered as =safe-local-variable= so Emacs won't
prompt for confirmation. To customize keywords or colors, set
=sailor-keyword-faces= -- see =site-lisp/sailor.el= for the
default list and shape.

** Meow
Define some leader keys. Example:
#+begin_src elisp
(meow-leader-define-key
 '("t" . yilin/open-with-terminal)
 '("e" . yilin/open-with-finder-or-default-app))
#+end_src
